# SVASTH

SVASTH is a full-stack healthcare appointment platform prototype with:

- a modern landing page and patient dashboard
- doctor workflow views and appointment booking flow
- QR-code-based check-in simulation
- email/WhatsApp confirmation responses from the backend API

## Run locally

```bash
npm install
npm run dev
```

- Frontend: http://localhost:5173
- Backend: http://localhost:5000/api/health

## Project structure

- frontend/: React + Vite client
- backend/: Express API server
